# ETEC PW3 — Login verde-menta

HTML, CSS e JavaScript com Supabase Auth (cadastro, login, recuperação, sessão e logout).

Supabase conectado ao projeto `ETEC-PW3-Login-Menta`.

## Publicação GitHub Pages
Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

Endereço: https://lunidrs.github.io/ETEC-PW3-Login/

## Supabase
Em Authentication → URL Configuration adicione `https://lunidrs.github.io/ETEC-PW3-Login/` em Site URL e Redirect URLs. Ative o provider Email se necessário. Nunca publique chaves secret/service_role.
